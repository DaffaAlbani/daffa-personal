# Impeccable Design Framework Skill

Use this skill when the user requests Impeccable design framework operations such as:
- `/impeccable init`: Initialize `PRODUCT.md` and `DESIGN.md` in the project root.
- `/impeccable update`: Update context files with latest project changes.
- `/impeccable audit`: Perform UX/UI audit checking for accessibility, colors, spacing, typography, and AI design anti-patterns.
- `/impeccable polish`: Refine UI components with glassmorphic depth, smooth transitions, and dynamic visual states.
- `/impeccable craft`: Create high-performance components following project design tokens.
